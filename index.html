Chèn Bảng Số Liệu (Chuẩn Word / Excel)
1. Chọn số dòng & số cột
2. Hoặc Dán dữ liệu từ Word / Excel / Google Sheets
Bạn có thể bôi đen bảng trong Word/Excel, bấm Ctrl+C rồi dán thẳng vào ô câu hỏi, hoặc dán vào khung bên dưới để chuyển thành bảng:
Danh sách Phím tắt Soạn thảo
Ctrl + Z : Hoàn tác (Undo)
Ctrl + Y : Làm lại (Redo)
Ctrl + B : In đậm (Bold)
Ctrl + I : In nghiêng (Italic)
Ctrl + U : Gạch chân (Underline)
Ctrl + V : Dán văn bản/bảng/ảnh
Delete : Xóa đối tượng/ảnh đã chọn
Esc : Đóng hộp thoại / Bỏ chọn ảnh
